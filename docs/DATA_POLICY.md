# นโยบายข้อมูลสำหรับฉบับ public

- Repo นี้เผยแพร่ **โค้ด, schema, และข้อมูลสังเคราะห์** เท่านั้น ยังไม่รวมชุดข้อมูลที่ผู้จัดงานหรือหน่วยงานอื่นมอบให้
- ข้อมูลจริงต้องเก็บในเครื่องและเข้า GraphDB local เป็นค่าเริ่มต้น ไม่ commit raw, normalized, RDF ที่สร้างจากข้อมูลจริง, backup, รายงานที่อาจมีข้อความต้นฉบับ หรือ volume ของ GraphDB
- อย่าคัดข้อความนิยามจากแหล่งภายนอกมาเป็น example โดยไม่มีสิทธิ์ Example ใน repo ต้องเขียนขึ้นเองและติดป้ายว่า synthetic
- การเก็บใน local ไม่ได้ทำให้มีสิทธิ์ใช้งานหรือส่งข้อมูลไป API ภายนอก ตรวจเงื่อนไข license, attribution, การประมวลผล และการส่งไป LLM ก่อนเปิด ThaiLLM
- ข้อมูลจากแหล่งหนึ่งไม่ใช่คำยืนยันของอีกแหล่ง ต้องรักษา source record ID, ฉบับ, ภาษา, license และหลักฐานของแต่ละระเบียน
- ความสัมพันธ์ที่จับคู่ด้วยคะแนนหรือ LLM เป็นข้อเสนอ ไม่ใช่ข้อเท็จจริงทางการ จนกว่าจะผ่านการตรวจ
- ก่อนเปิด public: โค้ดใช้ Apache-2.0 (ดู `LICENSE`) ซึ่งไม่ครอบคลุมไฟล์ข้อมูล นอกจากนั้นต้องตรวจสิทธิ์แบรนด์, สแกนความลับและไฟล์ Git ที่จะ push, ตรวจ dependency licenses, และทดสอบจาก clone ใหม่โดยไม่มีข้อมูลจริง

หมายเหตุ: การเปิดหน้าเว็บต่อสาธารณะไม่เท่ากับเปิดเฉพาะโค้ด หากต่อเว็บกับฐานข้อมูล local ที่มีเนื้อหามีข้อจำกัดการเผยแพร่ ผู้ใช้เว็บก็อาจเข้าถึงข้อความนั้นผ่าน API ได้ ต้องกำหนด policy แสดงผลแยกต่างหากก่อน deploy
